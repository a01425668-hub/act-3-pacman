# Actividad 3. Juego del Packman

Este proyecto contiene una versión modificada del clásico videojuego de Pacman. El código fuente original usado de base para este proyecto se puede encontrar en [Free Python Games](https://grantjenks.com/docs/freegames/pacman.html)

## Modificaciones

* **Cambio 1:** Se modificó el movimiento de los fantasmas para que fueran más inteligentes.
* **Cambio 2:** Se modificó el tablero.
* **Cambio 3:** Se aceleró el movimiento de los fantasmas.

## Ejecutar Localmente

Clona el proyecto

```bash
  git clone https://github.com/a01425668-hub/act-3-pacman.git
```

Ve al directorio

```bash
  cd act-3-pacman
```

Instala las librerías necesarias

```bash
  pip install freegames
```

Ejecuta el código

```bash
  python3 pacman.py
```
